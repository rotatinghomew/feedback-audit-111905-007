# 多语指引质量

本项目用于整理社区服务运营数据。`fixtures/` 保存本地合成源记录，各表字段和业务时序约定见 `DATA.md`。没有线上服务或真实个人信息。

## 生成发布就绪报告

```sh
python3 -m audit.report            # 打印 Markdown
python3 -m audit.report > report.md
```

报告逐节回答窗口与编辑关心的问题：

1. **现在能开哪些路线** —— 以“路线每一步都取得足额独立盲审且未被更正”为准，不用总通过率。
2. **按语言 × 语义风险的可比覆盖** —— 同时给出原始 equivalent 比例和合格覆盖率，并把缺内容、未独立复核、审校员对照不足、完全未审分开计数。
3. **实际路线卡在哪** —— 共享步骤只算一次证据，不因被多条路线引用而重复计数。
4. **语义陷阱与分歧辨别** —— 同一文本在不同来源版本下含义不同、等价码跨含义、审校员一侧判对一侧判错。
5. **复审时段怎么排** —— 同一人时段冲突、同稿/同义稿不算新独立人、跨语言不能互相顶替、取得资格的时点。
6. **更正后的下线与兜底** —— 只暂停受影响步骤，旧稿含同一错误时不能兜底，旧预约按登记承诺处理。
7. **尚在盲审** —— 回交前不作为通过。
8. **路线之外的覆盖缺口** —— 有译稿却从未出现在任何路线里的语义。

## 判定规则（与 `audit/rules.py` 一一对应）

| 规则 | 说明 |
| --- | --- |
| 盲审 | `seen_gold=yes` 的对照或文案判断都不算盲审。 |
| 对照资格 | 高风险判断要求在**判断当刻**已用盲审对照覆盖“同义”和“不可互换”两侧且全对；固定作答或只看一侧均不合格。 |
| 独立人数 | 高风险至少 2 名不同审校；同一人读同单元的多份同义稿仍只算 1 份。 |
| 更正 | `correction` 行使该单元所有语言的译本退出新发布，即使该译本曾被认可。 |
| 路线 | 任一步骤未达门槛即整条不可开；共享步骤不重复计证据。 |
| 低风险 | 只要能读懂即可，一名审校认可即足额；但仍须是盲审。 |
| 旧稿兜底 | 只替代**阻塞概念**；旧稿含同一错误或缺少该概念时不可兜底。 |
| 时段 | 同一人重叠时段只能选一项；跨语言共用的时段被占用即不可用。 |

## 测试

```sh
python3 -m unittest discover -s tests -v
```

`tests/test_fixtures.py` 校验源记录结构；`tests/test_audit.py` 逐条钉住上述规则的边界情况，改动源数据若悄悄放宽门槛会使其失败。
